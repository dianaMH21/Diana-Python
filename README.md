# Dashboard de Ventas Claro

Dashboard desarrollado en Python con Streamlit para análisis de ventas, comisiones y desempeño por asesor.

## Tecnologías
- Python
- Streamlit
- SQL Server
- Pandas

## Funcionalidades
- Comparativo D&C vs Teletalk
- Factor por fecha de instalación
- Factor por fecha de venta
- Ranking de asesores
